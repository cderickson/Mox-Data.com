# Mox Data

**Mox-Data.com** is a cloud-based data ingestion and analytics platform for **Magic: The Gathering Online**.

Players can upload raw MTGO gameplay files, process them into structured records, then explore and clean those records through tables and dashboards.

For usage walkthroughs, visit the **[Getting Started](https://mox-data.com/gettingstarted)** page.

## Latest Update

### v1.0.0 - Initial Release (2026-03-29)

- First public release of Mox Data (web-based MTGO-Tracker experience).
- Cloud-based ingestion for `GameLog` and `DraftLog` files.
- Core tables and analytics dashboards.
